## Lo que se le pidió
Solo el README y esta tarea, dicha igual a todos:
1. Instalar y abrir la app.
2. Generar los datos demo.
3. Hacerle al coach tres preguntas propias sobre las sesiones.
4. Pedirle que clasifique una app, y aprobar o rechazar la regla.
5. Probar un interruptor de error y decir qué entendió.
